Backups

Dá para fazer um backup agora quando o servidor deste PC estiver ligado e pronto.

Ainda não há backups neste PC.

O backup é uma cópia do mundo. O app faz uma sozinho de tempos em tempos enquanto este PC hospeda o servidor; o intervalo muda em Configurações › Backups.

    O mundo de agora é guardado num backup antes da troca, e dá para voltar a ele depois.

    Grupo

    Só o dono do grupo vê os PCs e cria convites. Você pode ver a lista de mods.

    PCs do grupo

      O PC tirado perde o acesso e precisa de um novo convite para voltar ao grupo.

      Convidar um PC

      Crie um convite e envie o texto a quem vai usar. Cada convite serve para um PC.

      Envie este texto só para quem vai usar. Ele vale uma vez e não fica salvo: se fechar esta tela, crie outro.

      Mods do grupo

      Todos os PCs do grupo usam estes mods. Só o dono do grupo muda a lista.

      Atualizando mods…

        O mod sai da lista e é apagado dos PCs do grupo na próxima atualização. Mods que são seus, fora da lista, não são mexidos.
