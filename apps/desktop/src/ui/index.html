      Configurações

      Geral

      Onde ficam o servidor, o mundo e os backups. Só dá para trocar com o servidor parado.

      O mundo e os backups atuais NÃO são movidos: continuam na pasta de hoje. O SabreHosting reinicia para usar a nova.

      Servidor

      De 3 a 32. Padrão: 10. Quanto maior, mais pesado.

      De 5 a 32, e menor que a distância de visão. Padrão: 8.

      Vale na próxima vez que o servidor for ligado.

      Só dá para trocar com o servidor parado. Convém ter um backup recente antes de trocar.

      Todos os PCs do grupo passam a usar esta versão.

      Backups

      De 1 a 1440. Padrão: 10. Vale já, com o servidor no ar.

      Os backups mais novos que ficam guardados (padrão: 10). Os dos últimos 7 dias sempre ficam, além destes. Os mais antigos são apagados sozinhos.

      A velocidade máxima, em megabytes por segundo, com que este PC baixa o mundo novo dos outros PCs (padrão: 10). Menor deixa a internet livre para jogar; maior atualiza mais rápido. Vale já a partir do próximo arquivo baixado.

      Cada backup novo também é copiado para a pasta escolhida (use a pasta do Drive, OneDrive ou Dropbox no seu PC). Se a pasta sumir, o backup deste PC continua normal.

      Padrão: 10, além dos últimos 7 dias, que sempre ficam. Os mais antigos são apagados da pasta sozinhos, e apagar na pasta também apaga na nuvem do serviço sincronizado.

      Endereço do servidor

      É o endereço que os amigos usam no Minecraft. Vem do grupo e não se muda aqui.

      Grupo

      PCs com acesso ao grupo. Só o dono do grupo vê esta área.

        O PC tirado perde o acesso e precisa de um novo convite para voltar ao grupo.

        Para um PC novo entrar no grupo, crie um convite e envie o texto a quem vai usar.

        Envie este texto só para quem vai usar. Ele vale uma vez e não fica salvo: se fechar esta tela, crie outro.

        Mods do grupo

        Todos os PCs do grupo usam estes mods. Só o dono do grupo muda a lista.

        Atualizando mods…

          O mod sai da lista e é apagado dos PCs do grupo na próxima atualização. Mods que são seus, fora da lista, não são mexidos.

          O link e o hash aparecem na página do arquivo, no Modrinth.
